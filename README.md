# Doc-Doc 🏥

A Flutter healthcare application focused on doctor discovery, appointment workflows, and a clean, responsive user experience.

## ✨ Overview

Doc-Doc is an advanced Flutter project built to practice and apply professional application-development concepts beyond UI implementation.

The project focuses on building a structured Flutter application with clear responsibilities, API integration, state management, generated models, dependency injection, and Firebase integration.

## 🛠️ Tech Stack

- **Flutter / Dart** — Cross-platform application development
- **BLoC / Cubit** — State management
- **Dio** — HTTP networking
- **Retrofit** — Typed API client generation
- **Freezed** — Immutable models and code generation
- **GetIt** — Dependency injection / service location
- **Firebase Core** — Firebase integration
- **Flutter ScreenUtil** — Responsive sizing
- **flutter_dotenv** — Environment configuration

## 🏗️ Engineering Focus

The project is structured around maintainability and separation of responsibilities rather than putting application logic directly inside UI code.

Key areas include:

- State management with BLoC/Cubit
- REST API integration
- Dependency injection
- Immutable data models and serialization
- Generated API/model code
- Responsive UI implementation
- Environment-based configuration
- Firebase integration

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code with Flutter support

### Installation

```bash
git clone https://github.com/TarekHayan/Doc-Doc-App.git
cd Doc-Doc-App
flutter pub get
```

Configure the required environment values for the project, then run:

```bash
flutter run
```
